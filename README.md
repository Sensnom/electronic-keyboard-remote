# Electronic Keyboard Remote

电子琴手机控制网页，包含曲目上传、演奏参数和信号日志三个页面。手机在本地读取MIDI，通过用户配置的WSS连接发送曲目和设置。

## 使用

1. 打开网页，连接设置已预填；可以直接连接并检查乐器，也可以修改地址、上下行主题及可选账号。
2. 在曲目上传页选择MIDI文件、练习轨道和速度，等乐器确认上传完成。
3. 在演奏参数页调整音量、音色、和弦、移调、八度、滑音和效果。可用项目取决于乐器固件，设置以乐器回传值为准。
4. 在信号日志页查看通信记录并导出。数字路径计时仅在设备提供相应能力时开放；未支持时不会显示测量值。
5. 三页之间通过站内导航切换，保留当前连接与文件；刷新页面后需重新连接和选择文件。

默认WSS地址为`wss://broker.emqx.io:8084/mqtt`，设备上行主题为`tof/flowmeter/data`，设备下行主题为`tof/flowmeter/down`，QoS为0，账号密码留空。所有连接字段均可修改。

网页不会自动连接，不保存密码或原始文件。使用自己的设备主题与受控账号。后台或锁屏可能中断上传，上传完成前请保持页面在前台。

## 部署

所有资源使用相对路径，可在GitHub Pages项目子路径部署。仓库根目录含index.html、parameters.html与logs.html，Settings → Pages选择main / (root)。不需要额外Node网页后端，仍需可供手机和乐器访问的MQTT服务，GitHub Pages不承担Broker功能。

MQTT.js浏览器包随网页提供，页面不依赖第三方CDN。连接地址需为浏览器信任证书的wss://入口。设备接线、供电和通信配置请按自己的硬件说明操作。

## 开发与验证

```sh
npm ci
npm test
```

测试需要Node.js、OpenSSL和Mosquitto，覆盖MIDI编译、二进制消息收发、应答与重试、参数范围和固件能力兼容。联网测试仅连接本机模拟设备。

更新浏览器依赖包时运行npm run vendor。不要上传账号、个人MIDI或其他私有文件。第三方组件的许可证随vendor目录提供；本项目网页源码尚未另行声明开放许可。
